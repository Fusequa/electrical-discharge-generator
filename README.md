# RC Generator for µEDM

Prototype RC relaxation generator designed for micro Electrical Discharge Machining (µEDM).
The project focuses on controlling discharge energy by changing resistance, capacitance, and supply voltage parameters.

# Features

|Feature|Description|
|-|-|
|Adjustable Voltage|Configurable input voltage for discharge control|
|Switchable R/C Values|Multiple resistance and capacitance combinations|
|Electrode Polarity Switching|EL+ / EL− selection|
|LCD Interface|Real-time parameter display|
|State Monitoring|Open circuit / machining / short-circuit indication|
|Voltage \& Current Measurement|Real-time monitoring of machining conditions|
|Arduino Control|Embedded control system using Arduino|

# Technologies Used

|Technology|Purpose|
|-|-|
|Arduino Uno|Main controller|
|AVR C/C++|Embedded firmware|
|MCP23017|GPIO expansion|
|LCD Display|User interface|
|UART|Serial communication|
|RC Relaxation Generator|µEDM pulse generation|

\---

# Project Goal

The aim of the project was to design and build a prototype RC generator for µEDM applications, enabling experimental control of discharge energy and machining conditions.
